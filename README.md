# Shreya Patha — Portfolio

A personal portfolio website built with React showcasing my skills, experience, projects, and GitHub activity as a Generative AI & AIML Developer.

## 🌐 Live Site

**[shreya661.github.io](https://shreya661.github.io)**

## ✨ Highlights

- Clean, responsive UI with dark/light theme toggle
- Smooth animations with Framer Motion
- GitHub calendar, streak, and stats cards
- Resume download link
- Section-based smooth scroll navigation

## 📌 Sections

- **Home** — Intro, animated typing roles, social links, resume button
- **About** — Bio and background as an AI/ML developer
- **Skills** — Tech stack: Python, FastAPI, LangChain, OpenAI, PyTorch, PostgreSQL, and more
- **Projects** — All 7 featured projects (IntervIO, EduBridge, NAVI 360, Journal AI, LaunchPad, ResearchAI, Sentiment Analysis)
- **Experience** — UpToSkills: AIML Team Lead & AIML Intern
- **Education** — TKR College of Engineering (B.Tech CSE - AI & ML) + Certifications
- **GitHub** — Calendar + streak + stats + top languages
- **Contact** — Email form, LinkedIn, GitHub links

## 🛠️ Tech Stack

- React 18
- Tailwind CSS
- Framer Motion
- React Scroll
- React Typical
- gh-pages (deployment)
